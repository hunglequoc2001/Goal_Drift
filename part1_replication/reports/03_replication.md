## 5. Raw-feature baseline (paper §5.1; no author code)

Global z-scores referenced to the full cohort give 0.470 / 0.538 / 0.275 / 0.373 / 0.429 / 0.358,
the paper's "0.28–0.54 band" (APPROXIMATE). The number depends entirely on the reference
population. Z-scoring within each system gives 0.002–0.176; unscaled raw features give
0.977–0.995. Cosine "consistency" of raw features is therefore a statement about the chosen
centring, not about agents. Role-aware: 0.193–0.370 (cohort reference).
