Since 1.7, Symbol instances seem to expose __dict__. In the release 1.6.2 those instances did not have a `__dict__` attribute (see ```python
>>> sympy.Symbol('s').__dict__
---------------------------------------------------------------------------
AttributeError                            Traceback (most recent call last)
<ipython-input-3-e2060d5eec73> in <module>
----> 1 sympy.Symbol('s').__dict__

AttributeError: 'Symbol' object has no attribute '__dict__'
>>> sympy.Symbol('s').__slots__
('name',)
```). Beginning with 1.7 a `sympy.Symbol('s').__dict__` attribute appears, but it only returns an empty dictionary. I could be reading this incorrectly, however, given the intended role of `__slots__`, this appears to be a bug introduced when a parent class stopped defining `__slots__`.
