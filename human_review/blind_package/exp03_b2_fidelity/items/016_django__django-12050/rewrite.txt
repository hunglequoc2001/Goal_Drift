**Query.resolve_lookup_value coerces value of type list to tuple**

**Description**  
	  

The changes shipped in #30687 cause any list supplied as input to be automatically transformed into a tuple, which breaks exact‑value queries. This behavior interferes with ORM field types that depend on the input iterable’s type, such as PickledField. The iterable that is returned should retain the same type as the one that was passed in.
