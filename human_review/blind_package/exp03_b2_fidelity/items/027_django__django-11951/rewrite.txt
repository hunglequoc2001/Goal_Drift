**Title:** bulk_create batch_size parameter interferes with the compatible batch size calculation  

**Description**  
	 
		(last modified by Ahmet Kucuk)
	   

**Location of the issue**  
The problematic line is https://github.com/django/django/blob/stable/2.2.x/django/db/models/query.py#L1197.  

**What I observe**  
The batch_size parameter ends up overriding the compatible batch size calculation. This seems incorrect because the routine bulk_update correctly chooses the minimum of the two values, as demonstrated by:  

https://github.com/django/django/blob/stable/2.2.x/django/db/models/query.py#L504  

**Suggested remedy**  
Apply the same conditional logic used in  

batch_size = min(batch_size, max_batch_size) if batch_size else max_batch_size  

to the code in bulk_create. I am prepared to open a PR to incorporate this change.
