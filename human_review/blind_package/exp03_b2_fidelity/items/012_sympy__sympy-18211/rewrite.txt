`solveset` should produce `ConditionSet`, yet it currently raises `NotImplementedError`.  
The root cause lies in ```julia
In [10]: Eq(n*cos(n) - 3*sin(n), 0).as_set()                                                                                                                  
---------------------------------------------------------------------------
NotImplementedError
```.  
In this situation, `solveset` throws `NotImplementedError`, while the function `solveset` is expected to return a `ConditionSet`. As a result, `as_set()` yields  
```julia
In [11]: ConditionSet(n, Eq(n*cos(n) - 3*sin(n), 0), Reals)                                                                                                   
Out[11]: {n | n ∊ ℝ ∧ n⋅cos(n) - 3⋅sin(n) = 0}
```.
