**Issue**  
Composed queries fail to alter the column list when using values()/values_list().

**Description**  
	  

**Observed behavior**  
When values()/values_list() is evaluated repeatedly, the column list remains unchanged, e.g.

**Additional details**  
>>> ReservedName.objects.create(name='a', order=2)  
>>> qs1 = ReservedName.objects.all()  
>>> print(qs1.union(qs1).values_list('name', 'order').get())  
('a', 2)  
>>> print(qs1.union(qs1).values_list('order').get())  
('a', 2)  

For further context, see compiler.py#L428‑L433.
