Fix for separability_matrix issue with nested CompoundModels
=========================================================

The issue was in the _cstack function which didn't properly
handle cases where left or right arguments were already
coordinate matrices (arrays) rather than Model objects.

Changed: _cstack function in astropy/modeling/separable.py
- Added helper function _get_coord_matrix to properly
  handle both Model objects and coordinate matrices
- Ensured robust handling of nested compound models
- Maintains backward compatibility
