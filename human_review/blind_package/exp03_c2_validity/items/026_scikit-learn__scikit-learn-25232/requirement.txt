When the initial_strategy parameter of IterativeImputer is set to "constant", the fill_value argument must be ignored. The imputer should always use SimpleImputer’s default constant (0 for numeric data and “missing_value” for string/object data) for the initial imputation, regardless of any fill_value passed by the user. This rule supersedes any previous expectation that fill_value would be propagated to the initial SimpleImputer.
