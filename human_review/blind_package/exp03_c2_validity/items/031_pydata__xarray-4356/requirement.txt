When a reduction operation (e.g., `sum`, `prod`, etc.) is called with the `min_count` argument together with more than one dimension (i.e., `dim` or `axis` is a sequence of length > 1), the `min_count` argument must be ignored. The function should issue a `UserWarning` with the message “min_count is ignored for reductions over multiple dimensions.” and then perform the reduction as if `min_count` had not been supplied. This requirement supersedes any previous expectation that `min_count` would be applied to multi‑dimensional reductions.
