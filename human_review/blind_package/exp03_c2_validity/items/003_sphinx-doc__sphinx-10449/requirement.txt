When the Sphinx configuration option `autodoc_typehints` is set to `"description"` and the target is `"all"`, the generated documentation must **not** display a “Return type” field for a class’s `__init__` method (i.e., constructors should not show a return type, even if it is annotated as `None`). This supersedes any previous expectation that the return type be shown for `__init__` methods.
